# ICONML
This is about the Machine Learning Prediction of lower thermospheric temperature observations by MIGHTI onboard the ICON satellite. This work has been accepted for publication in Advances in Space Reseacher, full reference as Bag, T., Sivakumar, V., Ogawa, Y., Nishiyama, T., Chakraborty, U., Singh, V., Machine Learning Prediction of lower thermospheric temperature observations by ICON/MIGHTI, Advances in Space Research (2026), doi: https://doi.org/10.1016/j.asr.2026.08.027
